# Logos du guide TV

La grille affiche le numéro de chaîne et, lorsque son nom figure dans
`TvGuidesHelper::CHANNEL_LOGOS`, son logo. Le navigateur charge directement
le fichier depuis Wikimedia Commons. Si l’image ne charge pas, le nom de
la chaîne est affiché. Les chaînes sans fichier approuvé conservent leur nom.
France 2, France 3, France 4 et France 5 utilisent un numéro coloré dessiné
en CSS ; ces quatre numéros ne téléchargent pas d’image.
