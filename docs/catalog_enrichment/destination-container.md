# Appartenance dans les destinations d’encodage

L’identification d’une vidéo autonome transmet son parent immédiat lorsque celui-ci
est une collection ou une série. `destination_container` contient sa nature, ses
titres et ses pays de production pour appliquer la convention de nommage existante.
Ce sont les données de la fiche vidb sélectionnée ; aucune recherche externe n’est
nécessaire. Aucun projet, fichier ou travail en file n’est modifié.

Les épisodes organisés par série et saison conservent les métadonnées de placement
existantes et leur dossier de saison. Une collection absente de vidb n’est pas
déduite à partir du seul titre du fichier.
