# Qualification multilingue observée

VM s’applique à une copie dont les pistes comprennent le français et au moins
une autre langue explicitement identifiée, sans piste de sous-titres. Cette
règle n’est pas spécifique à l’anglais ; ger/deu/de identifient notamment
l’allemand. Les codes acceptés et leurs alias sont explicites dans le service.
Un code absent, indéterminé, réservé ou non reconnu maintient le besoin d’examen.
Une piste de commentaire ou d’audiodescription ne prouve pas un second dialogue.
Les mentions VO/VOST, les indices contradictoires, les sous-titres et les projets
JSON associés restent soumis aux politiques spécifiques existantes.
Le suffixe historique _vf ne prime pas sur les pistes observées.

Le cas Ce qui reste (copie 943) possède deux pistes fre/ger et aucun sous-titre.
Il rejoint les quatre autres copies fre/eng : 1063, 1229, 1432 et 1935. Ces cinq
copies initialement non qualifiées peuvent recevoir VM après recontrôle de leur
identité, de leurs métadonnées et des pistes. La langue des fiches est préservée.
Aucun renommage ou déplacement physique n’est inclus dans cette opération.
