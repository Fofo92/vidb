Les 70 correspondances sont enregistrées dans CatalogueEpisodeLink. Le contrôle du 11 octobre 2026 retrouve chaque identifiant TMDB avec ses numéros locaux de saison et d’épisode. Le manifeste de préparation, qui contenait aussi l’ancien état des fiches, a été retiré. La base est la référence.

Décisions manuelles conservées :

- Le rang local est prioritaire pour le classement ; il ne doit pas être remplacé par la numérotation externe.
- S03 E04 : L’Express de Plymouth, titre original The Plymouth Express.
- Saison 12 : Les Pendules, Drame en trois actes, Le Crime d’Halloween, Le Crime de l’Orient-Express ; numéros TMDB E04, E01, E02, E03.
- Le titre Un, deux, trois... conserve ses trois points ; avec le séparateur de l’extension, le nom se termine par trois....m4v.
